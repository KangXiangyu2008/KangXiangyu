一个**单文件**网页：`index.html`。不依赖任何外部资源（无 CDN、无图片文件、无框架），断网双击也能正常打开。

## 本地查看

双击 `index.html` 即可（推荐 Chrome / Edge / 手机浏览器）。

## 部署上线（招新里「部署上线并通过网址直接访问」是加分项）

任选一种，都是一分钟的事：

**A. GitHub Pages**
1. 新建仓库（如 `kx-homepage`），把 `index.html` 传上去
2. 仓库 Settings → Pages → Source 选 `main` 分支 `/ (root)` → Save
3. 一分钟后访问 `https://<你的用户名>.github.io/kx-homepage/`

**B. Vercel / Netlify / Cloudflare Pages**
把 `index.html` 拖进它们网页上的部署区域，直接得到网址（不需命令行）。

**C. 不想留痕的临时演示**
`python -m http.server 8000`，然后同局域网手机访问 `http://电脑IP:8000` —— 可以当场用手机看（手机端体验也是加分项）。

## 交互与实现说明

- 深浅色主题切换（记住选择，跟随系统偏好）
- 滚动出现动画、导航自动高亮当前板块、回到顶部按钮
- 响应式布局：桌面端多栏、手机端单栏（390px 下无横向溢出，已实测）
- 全部为原生 HTML/CSS/JavaScript，无任何依赖
